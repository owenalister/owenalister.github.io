UE5 FPS

​First created in unreal engine 4.

​Multiplayer, featuring steam server browser, server authoritative gameplay and server side saves of player character.

First person shooter and survival game mechanics: Dynamic weapon aim position, projectile bullets, inventory system, building system, party system and multi-person vehicles.

​ ​C++ code with blueprints scripting used for UI and animation.

​​Worked on in spare time, upgraded to from UE4 all the way to UE5.6 to stay up to date with the latest engine features. Implemented features such as GAS, game features plugin and mutable. I have now moved to Mover2.0 and the network prediction plugin and am in the final stages of replacing GAS with an ability system I built from the ground up designed around the network prediction plugin framework.

​ ​Game design focused on fair pvp gameplay that doesn’t allow client-side tampering or advantages based on poor network conditions.​

  • Technology: UE5, C++, Network Prediction Plugin
